# UI Patterns

페이지별 레이아웃 패턴 카탈로그. `docs/design-system.md`의 토큰과 컴포넌트를 조합하여 사용한다.

## 페이지 레이아웃

### 게임 목록 페이지

```
┌─────────────────────────────────────────┐
│ Header (fixed)                          │
├─────────────────────────────────────────┤
│ Hero Section (선택적)                    │
│ "Game Park에 오신 것을 환영합니다"       │
├─────────────────────────────────────────┤
│ [장르 필터 탭]  [검색바]  [정렬 드롭다운] │
├─────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐    │
│ │ Game │ │ Game │ │ Game │ │ Game │    │
│ │ Card │ │ Card │ │ Card │ │ Card │    │
│ └──────┘ └──────┘ └──────┘ └──────┘    │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐    │
│ │ Game │ │ Game │ │ Game │ │ Game │    │
│ │ Card │ │ Card │ │ Card │ │ Card │    │
│ └──────┘ └──────┘ └──────┘ └──────┘    │
├─────────────────────────────────────────┤
│ Footer                                  │
└─────────────────────────────────────────┘
```

**구조:**

- 반응형 그리드: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`
- 장르 필터: 탭 또는 칩 형태, 가로 스크롤 가능
- 검색: 실시간 검색 (debounce 300ms)
- 정렬: 인기순, 최신순, 좋아요순

### 게임 상세 페이지

```
┌─────────────────────────────────────────┐
│ Header                                  │
├─────────────────────────────────────────┤
│ ← 뒤로가기                              │
├─────────────────────────────────────────┤
│ ┌────────────────────┐  게임 이름        │
│ │                    │  장르 뱃지         │
│ │   썸네일 이미지     │  설명 텍스트       │
│ │   (aspect-video)   │                   │
│ │                    │  [▶ 플레이] [♥ 좋아요] │
│ └────────────────────┘                   │
├─────────────────────────────────────────┤
│ 랭킹 테이블                              │
│ ┌─────┬──────────┬───────┐              │
│ │ 순위 │ 닉네임    │ 점수  │              │
│ ├─────┼──────────┼───────┤              │
│ │ 1   │ player1  │ 9999  │              │
│ │ 2   │ player2  │ 8888  │              │
│ └─────┴──────────┴───────┘              │
├─────────────────────────────────────────┤
│ Footer                                  │
└─────────────────────────────────────────┘
```

**구조:**

- 모바일: 썸네일 상단, 정보 하단 (세로 배치)
- 데스크톱: 썸네일 좌측, 정보 우측 (가로 배치) — `md:grid-cols-2`
- 플레이 버튼: 큰 CTA 버튼
- 좋아요: 낙관적 업데이트

### 게임 플레이 페이지 (풀스크린)

```
┌─────────────────────────────────────────┐
│ [← 나가기]  게임 이름    [⏸ 일시정지]    │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│            iframe (게임)                 │
│            (flex-1)                      │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

**구조:**

- `(fullscreen)` 레이아웃 사용 — 헤더/푸터 없음
- 상단 바: 게임 이름, 나가기, 일시정지
- iframe: 나머지 전체 영역 차지 (`flex-1`)
- 게임 종료 시 결과 모달 오버레이

## 공통 패턴

### 로딩 상태

모든 데이터 패칭 페이지에 스켈레톤 UI 제공:

```tsx
// loading.tsx
<div className="grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-3">
  {Array.from({ length: 8 }).map((_, i) => (
    <GameCardSkeleton key={i} />
  ))}
</div>
```

### 빈 상태

데이터가 없을 때:

```tsx
<div className="flex flex-col items-center justify-center py-16">
  <Icon className="text-muted-foreground mb-4 h-12 w-12" />
  <p className="text-lg font-medium">결과가 없습니다</p>
  <p className="text-muted-foreground text-sm">검색어를 변경해 보세요</p>
</div>
```

### 에러 상태

```tsx
// error.tsx
<div className="flex flex-col items-center justify-center py-16">
  <p className="text-lg font-medium">문제가 발생했습니다</p>
  <p className="text-muted-foreground mb-4 text-sm">{error.message}</p>
  <Button onClick={reset}>다시 시도</Button>
</div>
```

### 낙관적 업데이트 (좋아요)

```
1. 사용자 클릭 → 즉시 UI 업데이트 (count +1, 하트 채움)
2. 백그라운드 API 호출
3. 실패 시 롤백 (count -1, 하트 비움) + 토스트 알림
```

### 무한 스크롤 / 페이지네이션

게임 목록은 상황에 따라 선택:

- **페이지네이션**: 기본 추천 (SEO 유리)
- **무한 스크롤**: 모바일 UX 우선 시
