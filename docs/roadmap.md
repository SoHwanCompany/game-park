# Game Park 로드맵

> **세션 시작 시 이 파일을 읽고, 현재 스프린트의 미완료 태스크 중 다음 작업을 제안한다.**

## 로드맵 관리 규칙

- 태스크 상태: `[ ]` 미완료, `[x]` 완료, `[~]` 진행 중, `[-]` 보류
- 스프린트는 순서대로 진행한다. 현재 스프린트의 모든 태스크가 완료되어야 다음으로 넘어간다.
- 태스크 완료 시 날짜를 기록한다: `[x] 태스크 내용 (2026-04-15)`
- 새 태스크 추가 시 적절한 스프린트에 배치한다.
- `/roadmap` 커맨드로 상태 확인 및 업데이트가 가능하다.
